# Security Policy

## Reporting Security Vulnerabilities

We take the security of `invoixy-gcp-bootstrap` and customer environments seriously. If you discover a security vulnerability or potential issue, please report it responsibly.

### How to Report

- **Preferred Method**: Use [GitHub Private Vulnerability Reporting](https://github.com/28VYK/invoixy-gcp-bootstrap/security/advisories/new) on the repository.
- **Email Contact**: Send details directly to `security@invoixy.com`.

### Important Guidelines

- **Do NOT open public GitHub issues** for suspected security vulnerabilities.
- **Never include sensitive material** in reports, such as private keys, customer credentials, authorization tokens, or production project data.
- Provide clear reproduction steps and a description of the potential impact.

We will acknowledge receipt and coordinate fix verification prior to public disclosure.
